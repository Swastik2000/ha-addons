# Home Assistant Add-on Repository

Add this repository to Home Assistant:
**Settings → Add-ons → Add-on Store → ⋮ → Repositories →** paste this repo's URL.

## Add-ons

### CUPS + HPLIP Print Server
A CUPS print server that can actually drive **host-based HP LaserJets**
(M1132 / M1136 / P1102 / P1005), which the usual CUPS add-ons cannot, and
advertises the queue over mDNS so iPhones and iPads see it as **AirPrint**.
